Deployment Steps

  1. Click Copy to Clipboard above.
  2. Open the GitHub repo: finn299/axiosequity → dataroom-config.js
  3. Click the pencil icon (Edit this file).
  4. Select all (Cmd+A) and paste (Cmd+V) the copied content.
  5. Scroll down → Commit message: "Update access codes / data rooms" → Commit changes.
  6. Wait 1–2 minutes for Vercel auto-deploy.
  7. (Optional) Bump cache-buster version in all HTML files to force fresh load.
