3 · Project / Workstream Drive Folder IDs

Each project (Investor Portal) and workstream (Partner Portal) can display an auto-synced Drive folder view. Set the Drive Folder ID once; new PDFs added to the folder appear in the data room automatically without HTML changes.

How to get a Folder ID:
1. In Drive, right-click the project/workstream folder (e.g. 02-Drone Defense (SDR)) → Share → set permissions (Specific people or Anyone with link for testing)
2. Right-click the folder again → Get link
3. The URL format: https://drive.google.com/drive/folders/[FOLDER_ID]?usp=sharing
4. Copy the [FOLDER_ID] portion (between /folders/ and ?)
5. Paste it into investor-dataroom.html or partner-dataroom.html, replacing PASTE_FOLDER_ID_HERE for the matching project/workstream

4 · Google Drive Picker — Setup

One-time setup to enable PDF upload directly from this admin page. After configuration, the "Upload PDF" button in section 1 becomes active.

Current status: Checking…

Setup Steps (one-time)

  1. Create a Google Cloud Project (or use existing)
    Visit console.cloud.google.com → "New Project" → name it AXIOS EQUITY Admin (or any name)
  2. Enable APIs:
    • Go to APIs & Services → Library
    • Search and enable: Google Picker API
    • Search and enable: Google Drive API
  3. Configure OAuth Consent Screen:
    • APIs & Services → OAuth consent screen
    • User Type: External (or Internal if using Workspace)
    • App name: AXIOS EQUITY Admin
    • User support email: info@axiosequity.com
    • Authorized domains: axiosequity.com
    • Add scope: https://www.googleapis.com/auth/drive.file
    • Add yourself as a test user (info@axiosequity.com or whichever you use)
  4. Create OAuth 2.0 Client ID:
    • APIs & Services → Credentials → Create Credentials → OAuth client ID
    • Application type: Web application
    • Name: AXIOS EQUITY Admin Web
    • Authorized JavaScript origins (add all):
      • https://axiosequity.com
      • https://www.axiosequity.com
      • http://localhost:8080 (optional, for local testing)
    • Save → copy the Client ID (ends with .apps.googleusercontent.com)
  5. Create API Key:
    • APIs & Services → Credentials → Create Credentials → API key
    • Copy the key
    • (Recommended) Edit it → Restrict key → API restrictions → Restrict to Google Picker API
    • (Recommended) Website restrictions → add https://axiosequity.com/* and https://www.axiosequity.com/*
  6. Find Project Number (App ID):
    • Click the project name at top of Cloud Console
    • Copy the Project Number (numeric, e.g. 123456789012)
  7. Paste credentials into admin.html:
    Open admin.html in editor, find the GOOGLE_CONFIG block at the top of the script, replace:
    var GOOGLE_CONFIG = { clientId: 'PASTE_CLIENT_ID_HERE.apps.googleusercontent.com', apiKey: 'PASTE_API_KEY_HERE', appId: 'PASTE_PROJECT_NUMBER_HERE', scopes: 'https://www.googleapis.com/auth/drive.file' };
  8. Commit & push the updated admin.html. Reload the admin page — the Upload button should activate.
⚠ Security notes:
• OAuth Client ID and API Key are not secrets — they are designed to be embedded in client-side code, restricted by domain origin.
• Anyone visiting admin.html can attempt to use them, but the actions are limited to their own Drive permissions and the admin login gate (AXIOS EQUITY-ADMIN-2026).
• The drive.file scope only grants access to files created or opened by the user via the Picker (least privilege).
• Rotate the admin login code if compromise is suspected.

6 · Workflow guide

Standard procedure for adding a new document to a data room.

  1. Upload PDF to Google Drive: My Drive / WWW / AXIOS-DATAROOM / [Investor or Partner] / [Project or Workstream folder]
  2. Set sharing permissions on the file:
    • Right-click → Share → add specific investor/partner emails as Viewer
    • Click ⚙ Settings → uncheck "Viewers and commenters can see the option to download, print, and copy"
    • (Optional) Set expiration date
  3. Copy the File ID — open the file in Drive, the URL contains: https://drive.google.com/file/d/[FILE_ID]/view
  4. Generate the snippet using the form above
  5. Paste into the appropriate data room HTML file at the right project/workstream block
  6. Commit & push to GitHub. Vercel auto-deploys.
  7. Record the new entry in AXIOS-DATAROOM/_ACCESS-MATRIX.md
  8. Notify the relevant investor/partner that the document is available (optional)
⚠ Important:
• PDFs themselves must never be placed in AXIOS EQUITY LLC/ — only in AXIOS-DATAROOM/
• Always use Drive's "Specific people" sharing — never "Anyone with the link"
• Rotate portal access codes every 6 months: see investor-login.html and partner-login.html
• Review Drive Activity log monthly for unusual access patterns
